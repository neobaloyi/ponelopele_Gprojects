# Ponelopele G Projects Website

Static advertising website built with HTML, CSS and JavaScript only.

## Files

- `index.html` — main SEO-optimised page
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation, scroll reveal and footer year
- `robots.txt` — crawler instructions
- `sitemap.xml` — search-engine sitemap
- `images/` — place future business/brand images here

## Email enquiries

The website uses `mailto:` links that open the visitor's configured email application with:

To: sales@ponelopele.com

## Before publishing

1. Replace `https://ponelopele.com/` if the live domain is different.
2. Add the company's physical address and telephone number if they should be public.
3. Replace/add professional company photography in `images/`.
4. Verify the business details in the JSON-LD structured data.
5. Submit `sitemap.xml` to Google Search Console after the site goes live.
